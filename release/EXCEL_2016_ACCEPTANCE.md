# Windows Excel 2016 人工验收回执

状态：人工验收清单。GitHub Actions 不包含 Excel 2016，不能代替本验收。
仅使用 tools/release_smoke.py 生成的纯虚构数据，不使用公司或员工真实资料。

请记录：验收日期、Windows 版本、Excel 产品版本及位数、ZIP 文件 SHA-256。

1. 从待确认发行包解压完整目录至含中文的路径，双击 exe。记录界面是否正常，
   是否出现 Tcl/Tk 或 DLL 缺失错误。关闭并重新打开应用。
   Windows 10/11 需要微软官方 VC++ 2015–2022 x64 运行库；本 ZIP 不捆绑 Microsoft
   DLL。缺少时先按 README 的官方链接安装，勿从第三方 DLL 网站下载文件。
2. 以合成复杂 HR 文件逐表配置记录识别和文本／数值保护，执行脱敏。
   检查脱敏文件能在 Excel 2016 打开，且未提示修复工作簿。
3. 添加分析 Sheet、兼容公式 SUM、IF、VLOOKUP 或 INDEX/MATCH；排序完整记录。
   保留记录识别列及受保护字段，保存并关闭 Excel。
4. 重新启动工具，选择返回文件，确认批次自动识别，Compare 干净场景无未确认项。
   Restore 后在 Excel 2016 打开，使用 Ctrl+Alt+F9 全量重算并核对合计。
5. 核对受保护单元格恢复、AI 新增公式、原有图表、格式及隐藏表。
6. 单独建立有意改动受保护字段／识别列的副本，验证提示冲突或人工核对，
   不会错误覆盖。不要把存在未完成项的输出当作完整恢复。
7. 关闭工具、重启 Windows 后重复加载同批次返回文件与恢复。验收本地账本
   持久化不依赖 exe 所在目录；不要删除、移动或分享私有恢复资料。
8. .xlsm 必须被拒绝。测试失败时保留证据，不提供真实值、账本明文或密钥。

## 随包纯虚构样例的复现配置

文件为 ZIP 根目录的 `SYNTHETIC_HR.xlsx`。不要使用旧证据包或真实员工数据。
下面使用 Excel 物理列字母，便于核对重复表头。

| 工作表 | 表头行 | 记录识别 | 文本保护列 | 数值保护列 |
| --- | --- | --- | --- | --- |
| 人员历史 | 2 | A + B | B、C、V、W、X、Y、Z | N、O、P、Q、R、S、T |
| 人员快照 | 1 | A | A、B、V、W | I、J、K、N、O、P |
| 薪酬明细 | 3 | A + B | B、C、M | G、I |

取消“隐藏配置”和“原有汇总”的参与勾选；它们仅含虚构公共测试说明。
薪酬明细 G 放本地 A 组、I 放本地 B 组；把人员历史 O 与人员快照 J
显式加入同一跨表共享组。逐表确认后执行脱敏。
干净场景应有 1,265 个受保护单元格，全部可恢复。此数量仅针对该样例和配置。
