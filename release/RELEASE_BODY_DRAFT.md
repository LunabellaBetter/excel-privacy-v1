# Excel Privacy Tool V1.0.0

开发者：LunaBella

本地 Excel 字段保护、AI 修改比对与安全恢复工具，提供 macOS Apple Silicon 和 Windows x64 免安装包。

## 功能与范围

- 对明确选择的文本与数值字段进行保护，本地加密账本支持恢复。
- AI 编辑后先 Compare，再按记录身份和受保护值检查执行 Restore；存在冲突或未确认项时需人工核对。
- 仅支持未加密 `.xlsx`。不支持 `.xlsm`、VBA、旧版 `.xls`、透视表、切片器、外部连接、嵌入对象等高级内容。
- 仅保护所选字段，不保证整个工作簿完全匿名；原件、恢复文件、密钥和账本不得上传外部 AI。

## 下载与安装

- `Excel-Privacy-1.0.0-windows-x64.zip`：Windows 10/11 x64，完整解压后运行 exe。需要微软官方 Visual C++ 2015–2022 x64 运行库，包内不分发 Microsoft 运行库 DLL；EXE 未签名。
- `Excel-Privacy-1.0.0-macos-arm64.zip`：Apple Silicon，解压后将 app 放入本地目录运行。应用仅临时签名，未经 Apple 公证；核对来源与哈希后按系统“隐私与安全性”提示打开，不要全局关闭 Gatekeeper。
- `SHA256SUMS.txt`：用于核对下载完整性。

安装步骤、资料保存位置和限制见随包 README。仅使用随包纯虚构 `SYNTHETIC_HR.xlsx` 进行首次验证。

## 验证状态与已知限制

双平台原生自动化已验证中文路径、跨进程恢复、1,265/1,265 受保护单元格精确恢复、AI 公式保留及图表和隐藏表保留。用户报告已在 Windows Excel 2016 完成脱敏 → AI 修改模拟 → Compare → Restore、1,265 处恢复与实际公式重算、整机重启后同批次恢复。

用户报告确认：受保护姓名修改会保留 AI 值并提示冲突；识别列修改会停止相关行自动恢复；脱敏样例中指定隐私标记残留为 0。这些结果仅针对验收样例，不代表所有 Excel 文件兼容或完全匿名。数值保护可能保留相对关系并受已知值推断；仍需检查未保护字段、自由文本和元数据。详见 `release/ACCEPTANCE.md` 和 `release/EXCEL_2016_ACCEPTANCE.md`。

独立发行源码采用 MIT；第三方组件遵循各自许可，完整声明随源码和安装包提供。
